# 🍳 Recipe RAG Chatbot

An intelligent, context-aware Recipe Assistant powered by **Retrieval-Augmented Generation (RAG)**. This chatbot indexes culinary cookbooks and recipe guides in PDF format, performs semantic search using dense vector embeddings, and generates answers using Hugging Face's state-of-the-art **Qwen2.5-72B-Instruct** model—complete with source document citations and page references.

---

## 🌟 Features

- **Document Processing**: Extracts text from multiple recipe PDFs using `PyMuPDF`.
- **Intelligent Chunking**: Splits text into context-rich passages with overlap via `RecursiveCharacterTextSplitter`.
- **Local Dense Embeddings**: Uses `sentence-transformers/all-MiniLM-L6-v2` locally for fast vector generation.
- **Persistent Vector Store**: Stores embeddings in a local `chromadb` instance without external database dependencies.
- **Advanced LLM Inference**: Connects to `Qwen/Qwen2.5-72B-Instruct` via the Hugging Face Inference API for clear answers.
- **Source Attribution**: Returns the original PDF document name and page number for every retrieved answer.

## 🚀 Getting Started

### 1. Prerequisites

- Python 3.10 or higher
- A free [Hugging Face Account](https://huggingface.co/) and an [API User Access Token](https://huggingface.co/settings/tokens)

### 2. Clone Repository

```bash
git clone https://github.com/iar01/silver-train.git
cd silver-train
```

### 3. Set Up Virtual Environment

```bash
# Create virtual environment
python -m venv .venv

# Activate on Windows (PowerShell)
.venv\Scripts\Activate.ps1

# Activate on Linux / macOS
source .venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure API Token

Copy the `.env.example` file to `.env`:

```bash
cp .env.example .env
```

Open `.env` and add your Hugging Face API token:

```env
HUGGINGFACEHUB_API_TOKEN=your_huggingface_api_token_here
```

## 📖 Usage

### Step 1: Ingest Data and Build Vector Database

Run the database setup script to parse PDFs in the `data/` folder and generate Chroma vector embeddings:

```bash
python setup_db.py
```

*This will read all `.pdf` files from `data/`, generate chunks, and save the persistent vector store into `./chroma_db`.*

### Step 2: Start the Chatbot

Run the interactive chat application:

```bash
python chatbot.py
```

Type your culinary questions in the prompt, such as:
- *"What ingredients do I need for traditional Arabian Gulf biryani?"*
- *"Can you give me a quick healthy dinner recipe from Middle Eastern cuisine?"*
- *"How do I make a simple student-friendly pasta dish?"*

Type `exit` or `quit` to end the session.

---

## ⚙️ Customization

- **Add New Recipes**: Drop any additional PDF books into the `data/` folder and re-run `python setup_db.py`.
- **Change Embedding Model**: Modify `model_name` in `setup_db.py` and `chatbot.py` (e.g., `BAAI/bge-small-en-v1.5`).
- **Change LLM Model**: Update `repo_id` in `chatbot.py` to another supported Hugging Face model.
- **Adjust Retrieval Size**: Tweak `k` in `retriever = vector_db.as_retriever(search_kwargs={"k": 3})` to fetch more or fewer context chunks.
